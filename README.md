# Shree Bhoj Vidhya Peeth HSS — Website

A responsive static website built with plain HTML, CSS and JavaScript.

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Keep the `assets` folder beside `index.html`; the page loads its images from that folder.

For the best local preview, use VS Code with the Live Server extension, or run a simple static server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Included

- Responsive desktop and mobile layouts
- School logo and colours based on the supplied logo
- School details visible in the supplied Instagram profile screenshot
- Photo gallery with click-to-enlarge lightbox
- Mobile navigation and scroll reveal effects
- Google Maps search link for the supplied address

## Before publishing

Please confirm the school's official spelling, address formatting and any additional details. Phone number, email, classes offered, admission dates, timings and affiliation were not visible in the supplied reference, so they have not been invented or displayed. The gallery images are crops from the supplied Instagram screenshot; replace them with original, high-resolution school photographs when available.

The Google Fonts import is optional. If offline, the page falls back to Georgia and Arial.
